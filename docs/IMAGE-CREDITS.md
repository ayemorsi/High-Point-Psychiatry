# Image credits

Every photo in `public/images/people/` is an AI-generated image supplied by High Point Psychiatry. Nobody in them is a real person, a patient or a member of staff, so they must never be presented as testimonials or as the practice's providers.

`src/lib/images.ts` lists each file and its alt text. To swap a photo, replace the file and keep its name.

## Insurance logos

`public/images/insurance/*.svg` are the insurers' own trademarked logos, downloaded from Wikimedia Commons and Wikipedia (Aetna, Blue Cross Blue Shield Association, Humana, McLaren Health Care, Molina Healthcare). They're shown only to say the practice accepts these plans. If an insurer's provider portal offers an approved logo, prefer that file and keep the same name.

Government programs (Medicare, Medicaid, Tricare, VA) are shown as names, not logos, because their marks are restricted.
